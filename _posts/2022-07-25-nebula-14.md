We also have a token in this directory: 

![](/assets/images/9baead766ce3ec9940c40.png)

So, the token is **857:g67?5ABBo:BtDA?tIvLDKL{MQPSRQWW.** and we need to decrypt it. 

It sounds like a quite basic cryptography that can be solved without any technical skills, but I decided to write a script. I would intentionally not share the source code of it, as it's the main takeaway of this level - sometimes you need to write simple stuff to test your theories, and you'd need some proficiency in the scripting languages (python, bash, etc.)
